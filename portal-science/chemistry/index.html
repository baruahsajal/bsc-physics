Core Kinematic Parameters

Summary of fundamental formulas required for solving numerical problems related to rectilinear motion.

Parameter Formula SI Unit
Speed ($v$) $$v = \frac{s}{t}$$ $\text{m/s}$
Velocity ($v$) $$v = \frac{\text{Displacement}}{\text{Time}}$$ $\text{m/s}$
Acceleration ($a$) $$a = \frac{v - u}{t}$$ $\text{m/s}^2$
Average Speed $$\text{Total Distance} / \text{Total Time}$$ $\text{m/s}$

Equation Name Formula Expression Variables Related

Position-Time Relation $$s = ut + \frac{1}{2}at^2$$ Displacement, Time, Acceleration
